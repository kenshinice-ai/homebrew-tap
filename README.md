# kenshinice-ai/homebrew-tap

Homebrew formulae and casks from [Paradise Production · 天域文创](https://github.com/kenshinice-ai).

```bash
brew tap kenshinice-ai/tap
```

## Casks

| Cask | Description |
|---|---|
| [`pwe-ai-bar`](Casks/pwe-ai-bar.rb) | Menu-bar quota meter and sentinel for AI coding tools — [source](https://github.com/kenshinice-ai/pwe-ai-bar) |
| [`pwe-mac-monitor`](Casks/pwe-mac-monitor.rb) | Menu-bar hardware monitor for Apple Silicon Macs — [source](https://github.com/kenshinice-ai/pwemacmonitor) |

```bash
brew install --cask kenshinice-ai/tap/pwe-mac-monitor
```
